1. YE APP KYA HAI

Ye IS 800:2007 ke mutabik steel beam/column design check karne ka tool hai — bending, shear, deflection, compression, tension, aur biaxial bending sab ek jagah. Load aur section daalte hi saare checks automatically calculate ho jaate hain, poori formula-by-formula calculation ke saath.

2. ACCOUNT BANANA / LOGIN

Naya account:

  1. Login page par "Sign up" link dabayein
  2. Email + password (6+ characters) daalein
  3. "SIGN UP" dabayein — turant 3 free calculations mil jaate hain

Existing account:

  1. Email + password daalein
  2. "LOG IN" dabayein
  3. Password bhool gaye ho to "Forgot password?" se reset karein

3. USE KAISE KAREIN

Section choose karein

Left panel mein Profile Family (ISMB/ISLB/ISWB/ISHB/ISMC/Built-Up), Section Designation, aur Steel Grade select karein.

Member parameters

Member Type, Support Condition, Span (L), aur Deflection Limit set karein.

Loads daalein

  • GRAVITY tab: Dead Load, Live Load, Wind Load (UDL ya Point Loads)
  • HORIZONTAL tab: Side-wise/lateral force (jaise wind seedha bagal se dhakka de)
  • AXIAL tab: Axial tension/compression force (column/strut ke liye)
  • MOMENT tab: Koi extra applied moment manually

Results dekhein

Reactions, Max BM/SF, Deflection turant dikhte hain. "IS 800 DESIGN CHECKS" table mein har check ka PASS/FAIL aur UR (Utilization Ratio) dikhta hai — kisi bhi row par click karke poori calculation + remedy dekh sakte hain.

PDF Report / Save Design

"PDF REPORT" button se professional report banti hai. "SAVED DESIGNS" panel se design save/load/export-import kar sakte hain.

5. FAQ

Q: Calculation galat lag rahi hai?

Check row par click karke formula-by-formula calculation dekhein. Final construction se pehle hamesha ek licensed structural engineer se verify karayein — ye tool preliminary design assistance ke liye hai.

Q: Payment kar diya, access nahi mila?

Thodi der wait karein. 24 ghante se zyada ho gaye ho to WhatsApp par screenshot + email dobara bhej dein.

⚠️ Disclaimer: Ye tool sirf preliminary design assistance ke liye hai. Final drawings/approvals ke liye qualified structural engineer se verify zaroor karayein.
